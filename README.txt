# SneakerShop z panelem admina

1. Utwórz darmowy projekt w Firebase.
2. Włącz Authentication (Email/Password).
3. Włącz Firestore Database.
4. W pliku firebase.js wklej swoją konfigurację.
5. Dodaj konto administratora w Authentication.
6. Opublikuj folder na GitHub Pages lub Firebase Hosting.

Klienci otwierają index.html.
Ty dodajesz produkty przez admin.html po zalogowaniu.
